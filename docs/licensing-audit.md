# Licensing audit

Last reviewed: August 28, 2026.

This audit records the repository’s current licensing position without changing it. It is an engineering inventory, not legal advice.

## Current repository

The root `LICENSE` grants the MIT License for the Novelty Engine repository as published by its copyright holder. Source code, tests, documentation, website code, and the repository-owned Skill files are distributed on that basis unless a file carries a separate notice. This audit found no repository file that declares a conflicting first-party license.

Third-party packages, linked public sources, trademarks, and third-party artwork or content remain subject to their own licenses and rights. The MIT License cannot grant rights the project does not own.

## Downloadable Skill

`public/novelty-engine.zip` is generated from `skill/novelty-engine/`. Because those files are part of the MIT-licensed repository and carry no separate restriction, the downloadable Skill is currently distributed under MIT as well. A downloadable prompt or instruction file can be read, copied, and modified under that license; packaging cannot technically prevent inspection or copying.

## Generated research output

The repository does not currently state a separate license for user-specific generated research output. The MIT License clearly covers the software and Skill, but it should not be assumed to grant rights in third-party source excerpts, trademarks, user inputs, or facts presented with copyrighted expression. A future commercial policy should make an explicit output-licensing decision and address source excerpts and user-provided material.

## Future versions

A future version could use different terms only for newly published material the rights holder controls. That would require clearly separating components, notices, distribution artifacts, contribution terms, and documentation so users can tell which terms apply. Third-party dependencies would still retain their own licenses.

Versions already published under MIT remain available under the MIT grant received for those versions. Changing a later release does not revoke MIT rights already granted to recipients of earlier releases.

## Decision still needed

Before commercial launch, obtain professional review and decide whether generated output needs explicit terms, whether contributed code requires a contributor policy, and whether any repository-owned visual assets need individual attribution or licensing notices. Do not represent prompt secrecy or access control as copyright or license protection.
